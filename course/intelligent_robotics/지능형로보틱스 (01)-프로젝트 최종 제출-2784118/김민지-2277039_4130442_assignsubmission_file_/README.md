## Project Overview

### Project Title

Vision-based Autonomous Claw Machine using ROS2

### Project Description

This project aims to build a vision-based autonomous robotic claw machine system using ROS2. The system combines robot manipulation and computer vision to allow a robotic arm to perceive surrounding objects and automatically grasp target objects.

A Panda robotic arm is used in a simulated environment constructed with Gazebo, while MoveIt2 performs motion planning and camera sensors provide environmental information. The overall system is designed to recognize objects, estimate their locations, and autonomously execute pick-and-place operations.

---

## Project Objectives

* Build an integrated ROS2 robotic system
* Simulate a robotic claw machine environment
* Attach camera sensors to the robot manipulator
* Perform object perception and position estimation
* Automatically execute grasping actions
