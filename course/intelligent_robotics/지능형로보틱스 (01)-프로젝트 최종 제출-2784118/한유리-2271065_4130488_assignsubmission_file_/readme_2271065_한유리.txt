RGB-D 기반 실내 재고창고 선반 상품 확인 로봇 시스템

팀명: 호로록
팀원: 한유리 (2271065)

---

[프로젝트 설명]

본 프로젝트는 ROS2와 Gazebo 시뮬레이션 환경에서 동작하는 RGB-D 기반 실내 재고창고 선반 상품 확인 로봇 시스템이다. 사용자가 확인하고자 하는 상품 클래스(예: bottle, box, can)를 지정하면, 로봇은 창고 내부를 이동하며 목표 상품을 탐색한다.

로봇은 RGB-D 카메라를 이용하여 상품을 검출하고, Depth 정보를 활용하여 상품의 3차원 위치를 추정한다. 이후 생성된 맵 정보와 상품의 위치를 기반으로 선반 앞의 적절한 관측 위치를 계산하고, Nav2를 이용해 해당 위치까지 자율주행한다. 목적지에 도착한 후 상품을 다시 검출하여 최종적으로 상품의 존재 여부를 확인한다.

프로젝트는 Gazebo 기반 시뮬레이션 환경, RGB-D 센서, SLAM, Navigation, 객체 검출 기술을 통합하여 자율 이동 로봇의 전체 파이프라인을 구현하는 것을 목표로 한다.

---

[시스템 구성]

1. Simulation / Sensor Module

* Gazebo 환경에서 재고창고 맵 구성
* TurtleBot3 Waffle 기반 모바일 로봇 사용
* RGB-D 카메라 센서 탑재
* RGB 이미지, Depth 이미지, Point Cloud, Odometry 데이터 생성

2. Mapping / Localization Module

* RTAB-Map 기반 3D Mapping
* 로봇 위치 추정(Localization)
* 전역 좌표계 제공

3. Perception Module

* RGB 영상 기반 객체 검출
* Depth 정보를 이용한 객체 3D 위치 추정

4. Viewpoint Planning Module

* 객체 위치 기반 후보 관측 위치 생성
* 충돌 여부 및 가시성 평가
* 최적 관측 위치 선택

5. Navigation / Verification Module

* Nav2 기반 자율주행
* 목표 위치 이동
* 재검출을 통한 최종 상품 존재 여부 확인
