# 프로젝트 설명
신체적 제약이 있는 사용자가 실내 매장에서 특정 물품을 선택했을 때, 이동 로봇이 자율적으로 해당 위치까지 이동하고 물체를 집어 사용자에게 전달하는 시스템의 시뮬레이션 구현

# AI 사용 여부 및 사용 내용
챗봇형 AI 에이전트를 사용하였으며, 사용 내용은 다음과 같다.
- 시작 단계에서 프로젝트 폴더 구분 계획 및 생성

- TurtleBot3 Waffle Pi와 OpenManipulator-X 통합 과정에서 변수명 및 파라미터 통일, 디버깅
