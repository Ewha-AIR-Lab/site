지능형로보틱스 최종 프로젝트

팀명: RBT

팀원: 배지혜(2491016)

프로젝트 설명: 
 - 주제: 음성 명령과 음원 방향 정보를 활용한 실내 가정용 로봇 이동 제어 시스템
 - 로봇이 소리의 방향을 기준으로 움직이도록 음성 명령에 반응하게 하는 제어 시스템을 구축
 - 네 가지 명령: come here, back up, turn to me, stop

AI 사용 내용:
 - sound_source_node, behavior_controller_node 구현 및 디버깅에 전반적으로 사용
